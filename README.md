## Опис роботи

У межах лабораторної роботи реалізовано три рекурсивні функції для самостійного обходу ієрархічного дерева меню (`Node`) без використання сторонніх бібліотек:
1. **`printMenu(node, level)`** — виводить усю структуру меню в консоль із відступом у два пробіли на кожен рівень вкладеності (прямий обхід дерева).
2. **`countItems(node)`** — підраховує загальну кількість пунктів у дереві, враховуючи сам вузол та всі його підпункти, із фіксацією кількості рекурсивних викликів у `callCount`.
3. **`find(node, name)`** — виконує пошук пункту за назвою по всіх вузлах дерева (як проміжних категоріях, так і листках) і повертає `True` або `False`.

## Як запустити проєкт

1. Переконайтеся, що на комп'ютері встановлено **Python 3**:
   ```bash
   python --version
   ```

2. Перейдіть у папку лабораторної роботи `lab11`:
   ```bash
   cd lab11
   ```

3. Запустіть скрипт у терміналі:
   ```bash
   python lab11.py
   ```
   *(На Linux або macOS може знадобитися команда `python3 lab11.py`)*
